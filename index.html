    02 / THE DEFINITION IS PART OF THE WORK

    A passport is
    a set of questions.

    There is no single official schema here, and that is the opportunity. A digital passport is whatever record lets a later reader trust what an object is, where it came from and how it may be reused. Which questions belong in it is your decision, and you have to defend it.

    The pilot map works with one proposal: six layers, eighteen questions, the same for every object. Use it as a starting point to argue against.

    03 / WHERE THE DATA LIVES

    Who holds it,
    and how you reach them.

    Quarry, plant, laboratory, transporter, depot, designer, engineer, builder, authority, occupant. Each is a different source, with a different cost and a different evidence class.

    04 / IN CLASS, TODAY

    Build one passport.
    Defend every line.

    1. ChooseOne object you can actually reach: a wall, a stair, a facade panel, a building you pass every day.
    2. Ask firstWrite the questions before the answers. Decide which layers your passport needs; the six here are a proposal, not a standard.
    3. Name the handFor each question, which of the ten hands could answer it, and what would it cost you to get there?
    4. Grade the evidenceA photograph of a stamp on a brick is not the same class as a sentence from a website. Mark each answer: document, measured, spoken, secondary.
    5. Separate the two silencesFill in only what you can defend today. For the rest say which it is: no source yet, or never written down. Effort fixes the first. Nothing fixes the second.
    6. The circular questionIf this object were taken apart tomorrow, which of your entries would the next person to use the material still trust?

    Hand in: your list of questions, the passport filled as far as you can defend it, and one paragraph on what you could not reach and why.

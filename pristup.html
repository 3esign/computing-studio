way in.

A phone is an option for participating, not a test of what device you own.

Prepare before the room fills

Save the site while you have a connection. After the success message, the included pages and instruments can be reopened without a network. Linked external sources are not downloaded.

HTTPS or localhost required. Browser storage can be cleared or evicted; test once before relying on it in class.

Participate another way

  • Use the visible text, tables and keyboard controls. Animations start only when requested.
  • Questions can be printed. Work with a partner if you choose; agree an appropriate format with the teacher.
  • Colour supports labels; it is not the only carrier of an answer. You can pause every timed demonstration.

Your work stays here

No student login, analytics or answer collection. Saved answers and notes belong to this browser only. Export them if you need a copy. The hosting provider still receives ordinary web requests.

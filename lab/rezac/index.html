Toolpath explorer · Rezač 3000

Change a polygon and inspect an illustrative toolpath for one layer. The text describes a simplified sequence of moves; it is not printer-ready G-code. Do not send it to a machine.

Model limits

G0 alone does not lift Z. In this example, G0 marks XY travel without an E increment; extrusion is modelled by G1 with increasing E. Actual command behaviour depends on the machine. Homing, heating, retraction, collisions, acceleration, supports and machine limits are not handled. Animation speed is not physical feed speed.

Use a simple non-crossing polygon. This offset and infill heuristic does not validate self-intersections or guarantee that connecting segments remain inside concave shapes. Displayed totals are illustrative, not manufacturability or structural checks.

Read the path

Orange solid segments deposit modelled material. Grey dashed segments are non-extruding travel. A travel move is not automatically a head lift, defect or structural weakness. The highlighted line follows a teaching animation, not an executing printer.

The model treats line width as bead width and assumes a rectangular deposited cross-section. It uses 1.75 mm filament. Repeating one identical layer estimates totals; there is no generated full-height machine file.

Try a change

Compare one and three perimeter lines. This heuristic moves between closed rings without extruding; another path planner could connect them differently. “No travel” says only what this list contains.

Change layer height and compare layer count with ideal material use. Then change shape: identify what the model measures and what a real slicer would still need to validate.

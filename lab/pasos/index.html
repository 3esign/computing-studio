THE RULE THAT DECIDES

answerable(question, sources):
  have = question.sources ∩ sources
  need == 'all' ? have == question.sources
                : have ≠ ∅

state = not answerable       → blocked
        answerable, recorded → known
        answerable, no entry → lost

Effort moves a question out of blocked. Nothing moves it out of lost.

What this map is, and what it is not

The base is two hand-placed river centre lines and one frame, good to a few hundred metres. It is orientation, not a survey base, and there is no cadastre behind it. One drawing unit is the same number of metres across and down; the scale bar is computed from that, not drawn by eye.

Three objects are public landmarks. Their values come from general literature, which is why every one of them carries evidence class S and why the measured count stays at zero even with every source selected. Two objects are marked as constructed for class: every value in them is authored, and the evidence class describes the scenario, not a test report. Nothing here certifies a structure, values a component, or permits a reuse.

In class: build one passport

  1. Choose one object you can actually reach: a wall, a stair, a facade panel, a building you pass every day.
  2. Write the questions before the answers. Decide yourself which layers your passport needs; the eighteen here are one proposal, not a standard.
  3. For each question name the source that could answer it and the evidence class you would get. A photograph of a stamp on a brick is not the same class as a sentence from a website.
  4. Fill in only what you can defend today. Mark the rest as blocked or lost, and say which one it is.
  5. Last question, the circular one: if this object were taken apart tomorrow, which of your entries would still be trusted by the next person to use the material?

Where the data lives

Data about a building is not only in a file. It sits in the material itself (a stamp on a brick, a mark on a panel), in the technology of the time, in the hands that built it, in the designers and engineers who signed it, and in the chain that delivered it: quarry, brickworks, plant, timber yard, depot, transporter. Each of those is a different source with a different cost and a different evidence class — and each one can be lost without anyone noticing.

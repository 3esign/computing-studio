The active rule

θ(i,j) = A · sin(phase + 0.65i + 0.35j)

const A = amplitudeDegrees * Math.PI / 180;
for (let j = 0; j < rows; j++) {
  for (let i = 0; i < columns; i++) {
    const angle = A * Math.sin(phase + i*0.65 + j*0.35);
    // Rotate each 0.8 × 1.0 m panel about its center.
    drawPanel(i, j, angle);
  }
}

The active model / SI units

I = bh³/12 · δ = FL³/(3EI)
v(x) = Fx²(3L−x)/(6EI) · R = F · |M| = FL

const F = loadKN * 1000;     // N
const E = modulusGPa * 1e9;  // Pa
const b = widthMM / 1000;    // m
const h = depthMM / 1000;    // m
const I = b * h**3 / 12;     // m⁴
const delta = F * L**3 / (3 * E * I);
const v = x => F*x*x*(3*L-x) / (6*E*I);
const reaction = F, moment = F * L;

Euler–Bernoulli beam; constant rectangular section, linear elastic homogeneous material, ideal fixed support, point load, small slopes. Shear deformation, self-weight, stress, buckling and dynamics are excluded. Learning model; no compliance or safety assessment.

Sources: UIUC / Beam deflection · UIUC / Rectangular section I. This model defines downward deflection as positive.
